보이지 않는 신호.
맞아야 하는 임피던스.

RF 신호는 2.4 GHz (파장 약 12.5 cm)로 진동하는 민감한 에너지입니다. 칩셋, 패턴, 안테나가 모두 50옴(Ω)이라는 표준 규격을 맞추지 못하면 에너지는 방사되지 못하고 칩으로 반사되어 수신 거리 감소와 발열을 유발합니다. (VSWR 및 Return Loss 증가)

안테나도.
제품에 맞게.

  • Inverted-F (IFA) — 역F형 패턴 안테나: 공간 15×25mm, 방사 효율 70%~80%, 비용 Zero. 가장 추천하는 표준 방식 (스마트 센서, 비콘).
  • Ceramic Chip — 세라믹 칩 안테나: 공간 3×2mm, 방사 효율 20%~50%. 초소형 기기에 적합하나 효율이 낮음.
  • Wire & Monopole — 외장 휩 안테나: 31mm 길이, 방사 효율 80%~90%. 고성능 산업용 장비에 최적.

감 대신 계측.
VNA로 맞추는 정합.

Vector Network Analyzer 계측 장비의 Port Extension 상차 보정을 마친 후, S11 Smith Chart 상의 임피던스 궤적이 50Ω 중심점에 정확히 수렴하도록 Pi(π) 매칭 네트워크의 L, C 값을 정밀 조율합니다.
