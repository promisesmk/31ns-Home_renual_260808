Before you start

Start simply.
Prepare thoroughly.

PCB 3D Builder is a Windows program that builds a PCB 3D STEP from a single PADS ASCII (.asc) file. Without an ASC file, it can also work from DXF plus a placement file, or from board dimensions. This guide follows the v2.1 user manual and the program source. The program’s interface is in Korean, so button names are shown in Korean as they appear, with an English gloss.

  • Environment: Windows 10 / 11, 64-bit
  • Required (one of): a PADS ASCII (.asc) file, a DXF (with a placement file if needed), or board dimensions
  • Optional extras: BOM (bill of materials, Excel · CSV), part STEP · ZIP files, datasheet package drawing PDFs
  • Loading files: drop any file anywhere on the window and it goes to the right place. Excel · CSV files are recognized as placement files or BOMs by their content; drop a file on a row of the parts list to assign it to that part.

1. Design file input

Explanatory diagram · not a program screen

On first launch, choose a workflow. ASC and DXF are not a required pair: they are two input paths, and you start from either one (when you start from ASC, you can still add a DXF for the board outline). You cannot continue until you choose one.

① ASC fileFiles: one ASC (+ optional DXF for the board outline)
Pros: a single file, STEP includes silkscreen · copper · traces, board thickness hint detected automatically
Cons: PADS only
② DXF (+ placement file)Files: DXF top · bottom (one or more) + a placement file if needed
Pros: keeps the mechanical outline as drawn, works with CAD tools other than PADS, PADS DXF works without a placement file
Cons: no silkscreen or copper in the STEP (bare board only)
  1. After you choose a workflow, the Add files window opens. Drop all files at once and their types are detected; [확인] (OK) turns on when every required file is in.
  2. With an ASC file, the board outline · mounting holes · part placement (top/bottom) · pads · silkscreen · traces · copper are read, 3D auto-fill runs, and the Board check window opens.
  3. With a DXF file, the DXF input window asks whether it is the top or bottom and lets you add the other side’s DXF and a placement file. The program checks the DXF: for a PADS DXF that contains reference designators and footprints the placement file becomes optional, otherwise it is required. Without a placement file, it tells you which parts may be inaccurate.
  4. Add a BOM (optional) now or in step 2. It improves finding part models by part number.
  5. In the Board check window, confirm the outline source (ASC · DXF · manual) and the board thickness. Thickness must be confirmed before you can continue. When both ASC and DXF are present, the DXF takes priority for the outline.
  6. If needed, enter a height limit (enclosure inner height). Parts that exceed it are outlined in red and listed in the report.
  7. Pick a PCB color from the swatches (green · blue · red · black · white · yellow · purple · matte green) or [직접…] (Custom…), then continue with [다음 단계: 부품 3D →] (Next: Part 3D).

Start over at any time with [파일 다시 넣기…] (Reload files…) or [↺ 처음부터 다시 선택] (Choose again from the start), and reopen thickness · height limit · outline source with [보드 확인 · 변경…] (Board check · change…).

2. Part model check & adjust

Explanatory diagram · not a program screen

3D auto-fill and auto alignment

[3D 자동 채우기] (3D auto-fill) reuses parts already registered in the library and fills the rest with real models from the KiCad 3D library, then standard shapes, then simple pad-based models. STEP models are automatically turned to the orientation whose pins best fit the pads, and with ASC input the pin numbers are known, so IC pin 1 and diode polarity are aligned too. Automatic results are not always correct, so check them as described below.

Reading the 3D status

  • By default the parts list is grouped by 3D status. Click the 3D status header to filter by status; red means no 3D and orange means needs checking.
  • 3D status (as shown in the program): [사용자 3D추가] (user-added 3D) · [KiCad 3D] (real models); [직접 만든 3D] (self-made 3D) · [표준 자동생성] (standard auto-generated) · [간이 생성] (simple) (models built from dimensions or pads); [임시 박스] (temporary box) (a box showing size only); [없음] (none); and [확인 필요] (needs checking) · [1번핀 확인] (check pin 1).
  • The selected part blinks with a black dashed outline in the preview; selecting a bottom-side part switches to the bottom view. Use the search box to find footprints, reference designators or part numbers.

Filling parts without 3D

  • [온라인 검색] (Online search) → drop: select a part without 3D, search online, and drop the downloaded STEP · ZIP onto that row.
  • [STEP/ZIP 일괄추가] (Add STEP/ZIP in bulk): add several files at once; they are matched to parts by file name and part number. For batch matching, name each STEP file to match its Footprint name. When you add a ZIP, this applies to the individual STEP files inside it, not to the ZIP file name. Names are compared without the extension (.step · .stp), ignoring case and symbols such as - _ and spaces. Example: for the Footprint SOT-23, SOT-23.step or sot23.stp. Files that do not match are listed in the results window; assign them with [STEP/ZIP 개별지정] (Assign STEP/ZIP) or by dragging them onto the row.
  • [STEP/ZIP 개별지정] (Assign STEP/ZIP): assign a file to the selected part.
  • [등록 삭제] (Remove registration): removes a wrongly linked model; the next auto-fill searches for it again.
  • Color: click the leftmost cell of the list to set the 3D body color for that footprint (right-click to clear). It is saved to the library.

Part 3D from a datasheet PDF ([PDF로 3D 만들기] (Build 3D from PDF))

  1. Choose one of seven package types: two-sided gull-wing, four-sided gull-wing, no-lead, two-terminal chip, molded diode, cylindrical or box.
  2. Click [PDF 열기…] (Open PDF…) or drop a PDF onto the window, then read the dimension table with [PDF 치수 읽기] (Read PDF dimensions). Without a PDF, use [패드에서 추정] (Estimate from pads) or enter the dimensions manually.
  3. Compare the values in the dimension fields with the drawing, correct them, and check the shape with [미리보기] (Preview).
  4. [3D 등록] (Register 3D) registers the part, automatically fitted to its pads.

Because the dimension table is read as text, drawings that are images only may not be recognized automatically, and shapes outside the seven types cannot be built. Register such parts with STEP · ZIP files.

Check & adjust ([확인 / 보정] (Check / Adjust) or double-click a part)

The selected part opens in shaded top · fixed-angle 3D · front views using the STEP’s real colors, so you can compare it with its pads (gold, with a light-blue outline), pin 1 pad (pink) and silkscreen (white). This view shows one part, not the whole board.

  • Rotate Z by ±90° / 180°, X / Y by 90°
  • Enter coordinates (0.05–1 mm steps) or drag with the mouse
  • [⇊ 바닥을 PCB면(Z=0)에 맞춤] (Snap bottom to the PCB surface (Z=0))
  • Redo it with [자동 정렬 다시] (Auto-align again) · [임시 박스로] (Use a temporary box) · [↺ 처음 상태로] (Reset), and save with [저장 및 완료] (Save and finish).

Height check

Parts that exceed the height limit set in step 1 are outlined in red and listed on the height-overrun sheet of the Excel report.

3. Save & review

Explanatory diagram · not a program screen

Review in the preview

For the whole board, switch between the top view and the bottom view (mirrored left to right), with front and side views alongside. Drag to zoom into an area; click without dragging or press Esc to zoom back out. Choose how part names are shown (none · selected · all, reference designator or part number), and click a part to see its details.

Save for the purpose

  • [3D STEP 저장] (Save 3D STEP) — the main output: the 3D model for mechanical design. Choose the board surface (with ASC input: none / silkscreen / silkscreen + copper) and part-name engraving (none / selected / all). All options are on by default; the user manual’s example is a 130 × 100 mm board at about 150 MB and about 40 seconds. Saving runs separately, so you can keep working.

Extras

  • [미리보기 이미지 (PNG)] (Preview image (PNG)) — image export (for review and sharing)
  • [배치 리포트 (엑셀)] (Placement report (Excel)) — placement and review report

What the report lists

Placement list (배치목록)Every part’s reference designator · footprint · part number · side · X · Y · rotation · 3D status · height
No 3D (3D없음)Parts without a 3D model or left as a temporary box
Height overrun (높이초과)Parts over the height limit
Outside outline (외곽이탈)Parts outside the board outline

The report gathers what to check after the model is built to support design review; it does not replace a 3D interference check or a manufacturability review.

Check before manufacturing

The 3D models, STEP files and reports are reference material for design review. Part shapes, orientation, height and the board outline may differ from reality, so compare the dimensions and orientation with the original design before using them for mechanical design, manufacturing or production.

Parts library · KiCad 3D

Build your library once.
Use it across designs.

  • Shared team library: registered parts (alignment, STEP, models downloaded from KiCad) are saved to the library folder and reused automatically on the next board. Click the library folder path shown at the bottom left to switch to a NAS or shared folder so the team can share it. Default location: Documents\PCB3D_Library
  • KiCad 3D models: if KiCad is installed, the models in its install folder are used. Otherwise, only the models you need are downloaded (gitlab.com, raw.githubusercontent.com) and saved to the library folder.
  • Internet use: board files are processed on your PC. The internet is used to download the list and files of public KiCad models and to open a web browser from [온라인 검색] (Online search).
