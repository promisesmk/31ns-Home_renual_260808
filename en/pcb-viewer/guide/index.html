Before you start

Start simply.
Prepare thoroughly.

PCB 3D Builder is a Windows program that builds a PCB 3D STEP with its parts from your PCB design files. A single PADS ASCII (.asc) file is enough; without one, it can also work from Gerber plus a placement file, DXF plus a placement file, or board dimensions. This guide follows the 4.0 user manual. The program’s interface is in Korean, so button names are shown in Korean as they appear, with an English gloss.

  • Environment: Windows 10 / 11, 64-bit
  • Required (one of): a PADS ASCII (.asc) file, Gerber + placement file, a DXF (with a placement file if needed), or board dimensions
  • Optional extras: BOM (bill of materials, Excel · CSV), part STEP · ZIP files
  • Loading files: drop any file anywhere on the window and it goes to the right place. Several files, folders and ZIPs all work; you can even drop a whole delivery folder from your PCB vendor and the program finds the Gerbers, placement file and BOM inside.
.ascBoard input (most accurate)
Gerber folder · ZIP · Gerber filesBoard input (with a placement file). Gerber and drill files are recognized by content, not extension (.pho · .gbr · .art · .gtl · .drl, etc.).
.dxfBoard outline (BOT in the file name means bottom)
Excel · CSV · TXTRecognized as a placement file or BOM by content
.step · .stp · .zipPart 3D registration (after the board is open). Drop on a row of the parts list to assign it to that part. A ZIP with no 3D model is not registered, and you are told so.

What changed in 4.0: boards from Gerber + placement files, the board surface exactly as in the Gerbers (copper · exposed pads · silkscreen), a drag-and-drop start screen, a progress card with estimated time left, removing parts that have no 3D, a 20 mm default height limit, the board check window on every open, and faster preview and STEP export for large boards. Installing over 2.x or 3.0 keeps the parts library, settings and project files.

1. Design file input

Explanatory diagram · not a program screen

Drop the board files on the card in the middle of the start screen, or click [파일 선택] (Choose files). The workflow is picked from the files you add (ASC → Gerber → DXF).

① ASC fileFiles: one ASC (+ optional DXF for the board outline)
Pros: a single file · exact pin numbers · board thickness hint
Cons: PADS only
② Gerber + placement fileFiles: Gerber folder (ZIP) + placement file (+ optional BOM · DXF)
Pros: any CAD · files everyone gets for PCB orders and SMT · outline, mounting holes and copper exactly as in the Gerbers
Cons: no pin numbers, so pin 1 and polarity are estimated
③ DXF (+ placement file)Files: DXF top · bottom (one or more) + a placement file when needed
Pros: keeps the mechanical outline · PADS DXF works without a placement file
Cons: no silkscreen or copper in the STEP (bare board only)

ASC file

Reads the board outline, mounting holes, part placement (top/bottom), pads, silkscreen, traces and copper, and runs 3D auto-fill. Reads PADS files from PowerPCB V4 to the latest version (coordinate units BASIC · MILS · METRIC · INCHES).

Gerber + placement file (when there is no ASC)

  • Drop the Gerber folder (or ZIP) together with the placement file and the board opens right away. With Gerbers only, a window opens for the placement file.
  • The outline, drills (mounting holes), pads, copper and silkscreen come from the Gerbers; references, rotation, top/bottom, footprint and value come from the placement file. For Gerbers without a separate outline layer (PADS, etc.), the outline is found from lines on a drawing layer.
  • Placement file formats may differ by CAD: origin, Y direction, units (mm/mil) and bottom-side rotation rules are matched automatically to the Gerber pad positions.
  • Gerber pads are grouped per part into a footprint pad layout, which is used to find and fit the 3D. A Pins column in the placement file makes this more accurate; footprints with an uncertain pad grouping are flagged in the Board panel.
  • The board surface is exactly as in the Gerbers: exposed pads are copper where the solder mask is open, and the silkscreen is drawn minus the mask openings.
  • Gerbers carry no pin numbers, so IC pin 1 and diode polarity are estimated from the silkscreen. Parts that cannot be decided are marked “pin 1 check”; confirm them in the check/adjust window.

DXF (+ placement file)

A DXF opens the DXF input window: choose top or bottom, and add the other side’s DXF and a placement file (recommended). For a PADS DXF with references and footprints the placement file is optional, otherwise it is required. With only one side, you are told that only that side may be built in 3D.

Board check

  • Whatever the workflow, the Board check window (outline reference + thickness + height limit) opens once when a board is opened. Reopen it any time with [보드 확인 · 변경…] (Board check · change…).
  • The board thickness must be confirmed. A hint is read from ASC drawing text (1.6T, 1.0T/2Layer, etc.), but you cannot continue until you confirm it.
  • Height limit (enclosure inner height): taller parts are outlined in red. The default is 20 mm for top and bottom; 0 turns the check off.
  • Outline reference: ASC / Gerber / DXF / manual. In auto mode DXF → Gerber → ASC is used; manual takes width, height, corners and mounting holes.
  • PCB color: swatches (green · blue · red · black · white · yellow · purple · matte green) or custom. Applied to the preview and the STEP, and saved in the project file.

Estimated outline (flashing red)

When there is no Board Outline item and the outline is estimated from drawing lines, it flashes red in the preview, and the Board check window and Board panel show “estimated outline” with how to fix it in PADS. In PADS Layout, draw one closed outline with [Drafting] → [Board Outline and Cut Out] and export again for an exact outline. If you cannot edit the design, continue with the estimate or switch the outline reference to manual.

Progress card

While a board loads or 3D is built, a card in the middle of the screen shows the current task, a progress bar, elapsed time and estimated time left. The estimate comes from the last time the same file was opened (or the file size the first time) and improves with use; if it runs over, you are told it is taking longer than expected.

2. Part model check & adjust

Explanatory diagram · not a program screen

Reading the 3D status

  • BOM (optional): improves finding parts by part number. Any layout works (columns are detected).
  • By default the parts list is grouped by 3D status. Click the 3D status header to filter by status, or another header to sort by it.
  • 3D status: user-added 3D (your STEP) · KiCad 3D · generated package · standard auto-generated · simple · temporary box · none · needs check
  • 3D % at the right of the status bar is the share of parts that have 3D (not a task progress).
  • The selected part blinks with a black dashed outline in the preview; selecting a bottom-side part switches to the bottom view. Search footprints, references or part numbers; references show a representative one plus “and n more”.

3D auto-fill

Real models are found in the KiCad 3D library and fitted to the pads. With ASC input the pin numbers are exact, so IC pin 1 and diode polarity are aligned automatically.

  1. Real KiCad models: found by footprint, part type, BOM part number, the package code at the end of the part number (TI DBV · DBQ · PW, etc.), online part data (package name and body size from a JLCPCB/LCSC search by part number) and the pad layout (pin count · pitch · body size · exposed pad). It works even when the name has no package in it (e.g. LMR51606XF → SOT-23-6); the final choice is the model that actually fits the pads.
  2. Generated packages: without a KiCad model, the package that fits the pads is built from a package dictionary (SOIC · SOP · SSOP · QSOP · TSSOP · MSOP · SOT · SC-70 · PowerSSO · HSOP · QFN · DFN · LQFP · TQFP · SOD · SMA · SMB · SMC · PowerPAK · electrolytic capacitors · power inductors · crystals/oscillators · chip arrays and more), e.g. L9733XP → PowerSSO-28, a 220 µF electrolytic → 12.5 × 10 mm.
  3. Otherwise standard chip shapes, then simple pad-based 3D. Parts that are not packages, such as connectors and switches, need a STEP file.

The online check can be turned off in Settings. Only part numbers are sent, and results are saved in the library folder so the same part number is not asked again. Parts already searched are not searched again (removing a registration searches again).

Adding and fixing 3D

  • Parts without 3D (red dot): select → [온라인 검색] (Online search) → drop the downloaded STEP/ZIP onto that row
  • [STEP/ZIP 일괄추가] (Add STEP/ZIP in bulk): add several files at once; they are matched by file name and part number. The result window lists the registered 3D, ZIPs without a STEP, and files that matched no part.
  • [STEP/ZIP 개별지정] (Assign STEP/ZIP): assign a file to the selected part.
  • Color (leftmost cell): set the 3D body color for that footprint (right-click to clear). Saved to the library.
  • Check / adjust (double-click): shaded top · 3D · front views in the STEP’s real colors, compared with pads (gold), pin 1 pad (pink) and silkscreen (white). Rotate Z ±90° / 180°, X / Y 90°, enter coordinates (0.05–1 mm steps), drag with the mouse, and snap the bottom to the board surface.
  • Remove registration (Delete): removes the 3D registration (also from the shared library).

Removing parts without 3D

Select a part with no 3D registration and press remove registration: after a warning it is removed from this board’s parts list, preview and STEP. The 3D library and other boards are not affected; the removal is saved per board and can be undone with [지운 부품 되살리기] (Restore removed parts) in the Board panel.

Per-reference settings

3D is registered per footprint, so every part with the same footprint gets the same 3D. To treat one part differently, click it in the 3D view or right-click → [위치번호별 설정] (Per-reference settings), pick the reference, then choose:

  • Set this part separately: a separate footprint · reference row appears, and its STEP, check/adjust and color apply to that part only.
  • Remove only this part from 3D: only that part’s 3D is left out of the preview and the STEP.
  • Unlink a separate row to follow the footprint settings again. Settings are saved per board in the library.

3D free placement

With the purple F button on the preview toolbar (shortcut F), or right-click an empty spot in the 3D view → [여기에 3D 자유 배치] (Free-place 3D here), place parts that are not in the design (STEP · ZIP) anywhere on the board to check a concept or clearance.

  • They are shown in purple in the list and the preview; drag them in the 3D view to move them. Placed in the bottom view, they go on the bottom side.
  • Right-click → [자유 배치 편집] (Edit free placement): name · X · Y · rotation · side · lift height, center on board, duplicate, delete
  • They are included in the height and outside-board checks and in the STEP, and are saved per board.

Height check

Parts over the height limit from step 1 (20 mm by default) are outlined in red and listed in the Excel report.

3. Save & review

Explanatory diagram · not a program screen

Review in the preview

Top, front and side sections are shown together; the front · side button (V) shows the top view alone, larger. Switch top / bottom and choose part names (none / selected / all, reference or part number). Click a part to see its details.

Save for the purpose

  • 3D STEP — the main output: the 3D model for mechanical design. Choose the board surface (with ASC or Gerber input: none / silkscreen / silkscreen + copper) and part-name engraving (none / selected / all). The defaults are all options (silkscreen + copper, engraving all); a 130 × 100 mm board is about 120–180 MB and 40 seconds to 2 minutes. More surface makes a larger STEP. Saving runs in the background so you can keep working, with progress and time left on the saving STEP card at the top right of the 3D view and on the status bar.

Extras

  • Preview PNG — image for review and sharing
  • Placement report (Excel) — placement list, no 3D, height overruns, parts outside the board

The report gathers what to check after the model is built to support design review; it does not replace a 3D interference check or a manufacturability review.

Check before manufacturing

The 3D models, STEP files and reports are reference material for design review. Part shapes, orientation, height and the board outline may differ from reality, so compare the dimensions and orientation with the original design before using them for mechanical design, manufacturing or production.

Parts library · KiCad 3D

Build your library once.
Use it across designs.

  • Shared team library: registered parts (alignment, STEP, models downloaded from KiCad) are saved to the library folder and reused automatically on the next board. Point it to a NAS or shared folder with the folder change (team sharing) at the bottom left so the team can share it. Default: Documents\PCB3D_Library
  • KiCad 3D models: if KiCad is installed, the models in its install folder are used (no internet needed). Otherwise, only the models you need are downloaded (gitlab.com, raw.githubusercontent.com) and saved to the library folder.
  • Internet use: board data is never sent out. With the online part check on, only part numbers go to the JLCPCB part search.
  • Speed: 3D shapes and the board surface computed on the first load are cached in %LOCALAPPDATA%\PCB3D\cache, so the same board opens faster next time.

Troubleshooting

Stuck somewhere?
Here is the next step.

“Windows protected your PC” during installationClick [More info] → [Run anyway]. This is a normal warning for a program without a code signature. If there is no [Run anyway] button or a company PC blocks it, see If installation is blocked.
The board shape is wrong and parts appear outside itThe ASC has no board outline, so an outline is estimated from drawing lines. If the estimate is wrong, follow the PADS fix in 1. Design file input or switch the outline reference to manual.
Pin 1 or polarity is wrong on a Gerber boardGerbers have no pin numbers, so they are estimated from the silkscreen. Check parts marked “pin 1 check” against the pin 1 pad (pink) in check/adjust and rotate them. ASC input is exact when available.
Gerber pad grouping needs a checkA Pins column in the placement file makes grouping more accurate. Check the 3D of flagged footprints in check/adjust.
Cannot go to the next stepThe board thickness has not been confirmed. Confirm it in Board check · change.
The same 3D appears twice, top and bottomThe same footprint is used on both sides. Remove one side from the 3D with per-reference settings.
KiCad models or part data cannot be downloadedAllow gitlab.com, raw.githubusercontent.com and jlcpcb.com through the company firewall, or install KiCad on the PC.
The STEP file is too largeSet the board surface to none or silkscreen only, and part-name engraving to none.
Slow on first openComputed shapes are cached, so the same board opens faster next time. The time-left estimate on the progress card also improves with use.
