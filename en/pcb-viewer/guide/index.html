Before you start

Start simply.
Prepare thoroughly.

PCB 3D Builder is a Windows program that builds a PCB 3D model (STEP) with its parts from a single PADS ASCII (.asc) file. Without an ASC file, it can also work from DXF plus a placement file. This guide follows the 3.0 user manual. The program’s interface is in Korean, so button names are shown in Korean as they appear, with an English gloss.

  • Environment: Windows 10 / 11, 64-bit (about 1.5–1.8 GB on disk)
  • Required (one of): a PADS ASCII (.asc) file, or a DXF (with a placement file if needed)
  • Optional extras: BOM (bill of materials, Excel · CSV), part STEP · ZIP files
  • Loading files: drop a file anywhere on the window and it goes to the right place. .asc is the board input, .dxf the board outline (BOT in the file name means bottom), Excel · CSV is recognized as a placement file or BOM by its content (fix misread columns with [열 지정] (Assign columns)), and .step · .stp · .zip are registered as part 3D. Drop a file on a row of the parts list to assign it to that part.
  • Window layout: command bar at the top, 3D preview in the middle, panels on the right (Board Alt+1 · Part 3D Alt+2 · Check Alt+3 · Save Alt+4) with an icon rail, and a status bar at the bottom. The Board → Part 3D → Save chips on the command bar show how much is left at each step.
  • Updating from 2.x: run the 3.0 installer without removing the old version; it installs over it and keeps the parts library, settings and project files. Afterwards, open an ASC and run [3D 자동 채우기] (3D auto-fill) once to search again for the parts 2.x created automatically (parts you assigned or adjusted stay). The “3D from PDF” feature was removed in 3.0.

1. Design file input

Explanatory diagram · not a program screen

On the start screen, choose [ASC 열기] (Open ASC) or [DXF + 좌표 열기] (Open DXF + placement), or drag the files onto the window. ASC and DXF are not a required pair: they are two input paths, and you start from either one (when you start from ASC, you can still add a DXF for the board outline). Use ASC when you can: one file gives a STEP with silkscreen, copper and traces. In PADS, export it with File → Export → ASCII.

① ASC fileFiles: one ASC (+ optional DXF for the board outline)
STEP contents: board + parts + silkscreen · copper · traces
Board thickness: hint read automatically from drawing text (1.6T, 1.0T/2Layer, etc.)
Versions read: PADS PowerPCB V4 to the latest (coordinate units BASIC · MILS · METRIC · INCHES)
② DXF (+ placement file)Files: one or more DXF (top · bottom) + a placement file when needed
STEP contents: board + parts
Board thickness: entered manually
Files read: PADS DXF (carries references, footprints, rotation and side, so no placement file is needed) and mechanical CAD DXF
  1. With an ASC file, the board outline, mounting holes, part placement, pads, silkscreen and traces are read, and part 3D is filled from models already downloaded. The first open takes from tens of seconds to about a minute.
  2. In the Board check window, confirm the outline reference (ASC · DXF · manual) and the board thickness, then click [확인] (OK). The thickness must be confirmed even when a hint is filled in. When both ASC and DXF are present, the DXF takes priority; the program checks the DXF’s origin and units by how well it encloses the ASC parts.
  3. If needed, enter a height limit (top/bottom, mm, the enclosure’s inner height). Taller parts are outlined in red (0 = no check).
  4. Pick the PCB color in the Board panel from the swatches (green · blue · red · black · white · yellow · purple · matte green) or with the eyedropper. It applies to both the preview and the STEP.
  5. Add a BOM (optional) with [BOM 넣기] (Add BOM) or by dragging it in. It improves finding part models by part number.

Reopen the Board check window with [보드 확인·변경] (Board check · change) on the command bar, or start again with [처음부터 다시] (Start over).

Estimated outline (flashing red)

When the ASC or DXF has no PADS board outline, the program joins drawing-line (2D Line) pieces into an outline that encloses the parts. The outline then flashes red in the preview with the label “estimated outline · no PADS board outline”, and the Board panel and Board check window show a notice. You can keep working with it, but if the shape is wrong the height and outside-board checks may be wrong too. If you can edit the design, create the outline in PADS Layout:

  1. Turn on the layer with the outline drawing lines (2D Lines imported from DXF) and make sure there are no gaps.
  2. Choose [Drafting] toolbar → [Board Outline and Cut Out] and trace the drawing lines into one closed outline. Draw rounded corners with Arc.
  3. Delete the old outline drawing lines or move them to another layer.
  4. Export again with [File] → [Export] → ASCII (*.asc) and load it into the program.

If you cannot edit the design, continue with the estimated outline or switch the outline reference to [직접 입력] (Manual).

2. Part model check & adjust

Explanatory diagram · not a program screen

3D auto-fill and auto alignment

Opening an ASC uses only models already downloaded; [자동 채우기] (Auto-fill) (F5) in the Part 3D panel also searches the internet for KiCad models and part data. Parts are filled in this order:

  1. Real KiCad models: found by footprint, part type, BOM part number, the package code at the end of the part number (TI DBV · DBQ · PW, etc.), the package name from online part data, and the pad layout (pin count · pitch · body size · exposed pad); the model that actually fits the pads is chosen. It works even when the name has no package in it (e.g. LMR51606XF → SOT-23-6).
  2. Standard chip parts: 0402–2512 chip resistors, capacitors, inductors and similar.
  3. Generated packages: without a KiCad model, the package that fits the pads is picked from a package dictionary (SOIC · SOP · SSOP · QSOP · TSSOP · MSOP · SOT · SC-70 · PowerSSO · HSOP · QFN · DFN · LQFP · TQFP · SOD · SMA/SMB/SMC · PowerPAK · electrolytic capacitors · power inductors · crystals/oscillators · chip arrays) and leads are placed on the pads (e.g. L9733XP → PowerSSO-28).
  4. Simple shapes: otherwise, a rough shape is built from the pads.

With ASC input the pin numbers are read too, so IC pin 1 and diode polarity are aligned automatically. Parts that are not packages, such as connectors and switches, need a STEP file.

Reading the 3D status

The dot at the left of each row tells you what to do. Filter with the chips above the list (all · none · check · done), and hover over a dot for details.

RedNone · temporary box — no 3D was found, or a box stands in for it. Add a STEP/ZIP to replace it with real 3D.
OrangeNeeds check · pin 1 check · polarity check — could not be fitted to the pads automatically, or the shape is symmetric so the direction is uncertain. Fix position and rotation in check & adjust; compare with the pin 1 pad (pink) and rotate 180° if wrong.
BlueSimple · standard auto-generated · generated package — built shapes. Mostly fine as they are; replace simple shapes with a STEP when height or shape matters, and check the height of electrolytic capacitors.
GrayKiCad 3D · user-added 3D · removed from 3D · free placement — real models or parts you set yourself. Nothing to do.

Click a part in the preview to select it in the list; it blinks with a light-blue dashed outline and the status bar shows its reference, height and side.

Filling parts without 3D

  • BOM: adding an Excel · CSV BOM (any layout) improves finding parts by part number.
  • Temporary box for missing 3D (on by default): fills parts without 3D with a box of the height set next to it (default 1.0 mm).
  • [온라인 검색] (Online search): select a part, get a STEP/ZIP from SnapMagic · SamacSys · Ultra Librarian · Octopart, and drop it onto that row.
  • [STEP/ZIP 일괄 추가] (Add STEP/ZIP in bulk): add several files at once; they are matched to parts by file name and part number.
  • [STEP/ZIP 지정] (Assign STEP/ZIP): assign a file to the selected part.
  • [간이 3D] (Simple 3D): build a simple 3D from the pad shape.

Right-click a part row for check/adjust · online search · assign STEP/ZIP · simple 3D · 3D body color · hide in preview · per-reference settings · remove registration. Hiding only hides the part in the preview (it stays in the STEP); removing a registration also removes it from the shared library.

Check & adjust (double-click a part or press Enter)

Compares the 3D model with the pads (gold), pad positions (light-blue outline), pin 1 pad (pink) and the board top surface (green line).

  • Z −90° (Q) · Z +90° (E) · 180° pin 1 flip (R) · X / Y axis 90°
  • Enter coordinates or drag with the mouse; drop the bottom onto the board surface (F)
  • [자동 정렬 다시] (Auto-align again) · [처음 상태로] (Reset) · [임시 박스로] (Use a temporary box)

Adjustments and 3D registrations are saved per footprint in the library and apply to every part with that footprint and to the next board. To treat one part differently, use per-reference settings.

Per-reference settings

Give one part of a shared footprint its own 3D or adjustment, or remove it from the 3D. Only the program changes; the ASC is not edited. For example, if a test-pad footprint sits at the same spot on the top (TP11) and bottom (TP12) and you assign a sub-board 3D to it, the sub board appears twice, mirrored; remove the bottom one (TP12).

  1. Right-click the footprint row in the list.
  2. Choose [위치번호별 설정] (Per-reference settings) → pick the reference (top/bottom shown).
  3. Choose remove only this part from 3D or set this part separately. To undo, use put 3D back or unlink.

You can also click a part in the 3D view and right-click to choose directly. Settings are saved per board (ASC file name), stay when you reopen it, and [3D 자동 채우기] (3D auto-fill) leaves these parts alone.

3D free placement

Place parts that are not in the ASC (STEP · ZIP) anywhere on the board to check a concept or clearance — try another part on a finished board, or mount a sub board on the main board.

  • Place: the purple F button on the preview toolbar (shortcut F) or [3D 자유 배치] (3D free placement) on the Part 3D panel → choose a file → it lands in the board center. Or right-click an empty spot in the 3D view → [여기에 3D 자유 배치] (Free-place 3D here) to place it there (on the bottom side when in the bottom view).
  • Move: click a free-placed part and drag it; a purple dashed outline follows. Turn off the zoom or pan tool first.
  • [자유 배치 편집] (Edit free placement): name (reference), X · Y (mm), rotation (15° steps or typed), side (top/bottom), lift height (for spacers and stacking), duplicate (another one 5 mm along X) · delete. Fine rotation and moves are done in the check/adjust window.

Free-placed parts are included in the height and outside-board checks and in the STEP. They are saved per board, reappear when you reopen it, and do not show up on other boards.

Height check

Parts over the height limit from step 1 are outlined in red, parts outside the board in yellow, and both are listed in the Excel report.

3. Save & review

Explanatory diagram · not a program screen

Review in the preview

By default the preview shows top, front and side views together. Legend colors: gray = 3D model, blue = generated 3D, orange = temporary box, purple = free placement, red outline = height overrun, yellow outline = outside the board.

  • Fit all (Home) · zoom in (+) · zoom out (−) · mouse wheel; pan (or drag with the middle button)
  • Area zoom (Z): drag to enlarge an area; press ESC or click once to release.
  • Top / Bottom (B): switch between the view from above and from below (mirrored).
  • Part names (L): none · selected · all, reference or part number
  • Front · side sections (V): turn off to show only the top view, larger (default: on).

Check panel (Alt+3)

Shows the number of placed parts and how many have real 3D, generated 3D or temporary boxes, the board outline and thickness, the maximum height (top/bottom), and parts over the height limit or outside the board. Click a part in the list to jump to it. With an estimated outline, the board outline item shows a red exclamation mark.

Save for the purpose (Save panel, Alt+4)

  • 3D STEP (Ctrl+E) — the main output: the 3D model for mechanical design (default name <board>_3D.step). Choose the board surface (with ASC input: none / silkscreen / silkscreen + copper, default silkscreen + copper) and part-name engraving (none / selected / all, default all). A 130 × 100 mm board with the defaults is about 150 MB and takes about 40 seconds; set surface and engraving to none for a lighter file. Saving runs in the background while a green progress bar fills on the status bar, so you can keep working. Closing the program while saving cancels the save.

Extras

  • PNG — the current preview image (<board>_preview.png, for review and sharing)
  • Excel report — placement list, no 3D, height overruns, parts outside the board (<board>_report.xlsx)

To continue later, save a project (Ctrl+S) as a .p3d file; it reopens the added files, board settings and PCB color.

The report gathers what to check after the model is built to support design review; it does not replace a 3D interference check or a manufacturability review.

Check before manufacturing

The 3D models, STEP files and reports are reference material for design review. Part shapes, orientation, height and the board outline may differ from reality, so compare the dimensions and orientation with the original design before using them for mechanical design, manufacturing or production.

Parts library · KiCad 3D

Build your library once.
Use it across designs.

  • Shared team library: registered 3D (alignment, STEP, models downloaded from KiCad), per-reference settings, free placements and online check results are saved to the library folder and reused automatically on the next board. In Settings, use [변경…] (Change…) under the parts library folder to point it to a NAS or shared folder so the team can share it. Default location: Documents\PCB3D_Library
  • KiCad 3D models: if KiCad is installed, the models in its install folder are used. Otherwise, only the models you need are downloaded (gitlab.com, raw.githubusercontent.com).
  • Internet use: board files and design data are never sent out. The internet is used to download KiCad models, to open a web browser from [온라인 검색] (Online search), and for the online part check (on by default; only part numbers go to the JLCPCB/LCSC part search). The check can be turned off in Settings; parts are then found by name and pad layout only.
  • Help: hover over a button and click the ? badge that appears, or press F1 (help for the button under the mouse) or Shift+F1 (help mode: explains each button you click). New users can turn on labels under icons in Settings.

Troubleshooting

Stuck somewhere?
Here is the next step.

“Windows protected your PC” during installationClick [More info] → [Run anyway]. This is a normal warning for a program without a code signature. If there is no [Run anyway] button or a company PC blocks it, see If installation is blocked.
The board shape is wrong and parts appear outside itThe ASC has no board outline. Version 3.0 estimates an outline from drawing lines. If the estimate is wrong, follow the PADS fix in 1. Design file input or switch the outline reference to [직접 입력] (Manual).
A DXF was added but the outline is not usedIf the DXF’s origin or units differ from the ASC, it does not enclose the parts and is not used. Make sure the DXF was exported from the same design.
Cannot go to the next stepThe board thickness has not been confirmed. Confirm it in [보드 확인·변경] (Board check · change).
The same 3D appears twice, top and bottomThe same footprint is used on both sides. Remove one side from the 3D with per-reference settings.
KiCad models or part data cannot be downloadedAllow gitlab.com, raw.githubusercontent.com and jlcpcb.com through the company firewall, or install KiCad on the PC.
The STEP file is too largeSet the board surface to none or silkscreen only, and part-name engraving to none.
Slow on first openComputed shapes are cached in %LOCALAPPDATA%\PCB3D\cache, so the same board opens faster next time.
“ASC file not found” when opening a projectA .p3d file remembers where the original files were. Put the files back in place or add them again.
