시작하기 전에

시작은 가볍게.
준비는 빠짐없이.

PCB 3D Builder는 PADS ASCII(.asc) 파일 하나로 부품까지 올라간 PCB 3D 모델(STEP)을 만드는 Windows 프로그램입니다. ASC가 없으면 DXF와 좌표 파일로도 만들 수 있습니다. 이 가이드는 3.0 사용설명서를 바탕으로 하며, 버튼 이름은 프로그램 표기를 그대로 [ ] 안에 적었습니다.

  • 실행 환경: Windows 10 / 11, 64비트 (설치 용량 약 1.5~1.8GB)
  • 꼭 필요한 것(하나): PADS ASCII(.asc) 파일, 또는 DXF(필요하면 좌표 파일 함께)
  • 있으면 좋은 것(선택): BOM(부품 명세서, 엑셀 · CSV), 부품 STEP · ZIP
  • 파일 넣는 법: 파일은 창 어디에 끌어다 놓아도 알맞은 곳으로 들어갑니다. .asc는 보드 입력, .dxf는 보드 외형(파일명에 BOT이 있으면 Bottom), 엑셀 · CSV는 내용을 보고 좌표 파일인지 BOM인지 판단하고(잘못 읽었으면 [열 지정]), .step · .stp · .zip은 부품 3D로 등록합니다. 목록의 특정 행 위에 놓으면 그 부품에 바로 들어갑니다.
  • 화면 구성: 위쪽 명령 막대, 가운데 3D 미리보기, 오른쪽 패널(보드 Alt+1 · 부품 3D Alt+2 · 검사 Alt+3 · 저장 Alt+4)과 아이콘 레일, 아래 상태 막대. 명령 막대 오른쪽의 보드 → 부품 3D → 저장 칩이 남은 일을 개수로 보여 줍니다.
  • 2.x에서 업데이트: 이전 버전을 지우지 말고 3.0 설치 파일을 그대로 실행하면 덮어 설치되며, 부품 라이브러리 · 설정 · 프로젝트 파일은 그대로 유지됩니다. 업데이트 후 ASC를 열고 [3D 자동 채우기]를 한 번 누르면 2.x가 자동으로 만든 부품을 새 규칙으로 다시 찾습니다(직접 지정 · 보정한 부품은 그대로). 3.0에서는 ‘PDF로 3D 만들기’가 빠졌습니다.

1. 설계 파일 입력

설명용 도식 · 실제 프로그램 화면이 아님

처음 화면에서 [ASC 열기] 또는 [DXF + 좌표 열기]를 누르거나, 파일을 창에 끌어다 놓습니다. ASC와 DXF는 함께 넣어야 하는 조합이 아니라 둘 중 하나로 시작하는 입력 경로입니다(ASC로 시작할 때 보드 외형용 DXF를 더할 수는 있습니다). 가능하면 파일 하나로 실크 · 동박 · 배선까지 들어가는 ASC 방식을 쓰세요. PADS에서는 File → Export → ASCII로 내보냅니다.

① ASC 파일넣는 파일: ASC 1개 (+ 보드 외형용 DXF 선택)
STEP 내용: 보드 + 부품 + 실크 · 동박 · 배선
보드 두께: 도면 문구(1.6T, 1.0T/2Layer 등)에서 참고값 자동
읽는 버전: PADS PowerPCB V4 ~ 최신(좌표 단위 BASIC · MILS · METRIC · INCHES)
② DXF (+ 좌표 파일)넣는 파일: DXF Top · Bottom 하나 이상 + 좌표 파일(필요할 때)
STEP 내용: 보드 판 + 부품
보드 두께: 직접 입력
읽는 파일: PADS DXF(위치번호 · Footprint · 회전 · 면 정보가 있어 좌표 파일 없이도 가능), 기구 CAD DXF
  1. ASC를 넣으면 보드 외곽 · 장착홀 · 부품 배치 · 패드 · 실크 · 배선을 읽고, 이미 받아 둔 모델로 부품 3D를 채웁니다. 처음 열 때는 수십 초~1분 걸립니다.
  2. 보드 확인 창에서 외형 기준(ASC · DXF · 직접 입력)과 보드 두께를 확인하고 [확인]을 누릅니다. 두께는 참고값이 들어 있어도 확인해야 다음 단계로 넘어갑니다. ASC와 DXF가 모두 있으면 DXF가 우선하며, DXF 외곽은 ASC 부품을 얼마나 감싸는지로 원점 · 단위를 확인합니다.
  3. 필요하면 높이 제한(Top/Bottom, mm, 케이스 내부 높이)을 넣습니다. 넘는 부품은 빨간 테두리로 표시됩니다(0 = 검사 안 함).
  4. PCB 색상은 보드 패널에서 견본(그린 · 블루 · 레드 · 블랙 · 화이트 · 옐로 · 퍼플 · 매트 그린)이나 스포이트(직접)로 고릅니다. 미리보기와 STEP에 모두 적용됩니다.
  5. BOM(선택)은 [BOM 넣기]나 끌어다 놓기로 넣습니다. 넣으면 품번으로 부품 모델을 찾는 정확도가 올라갑니다.

보드 확인 창은 명령 막대의 [보드 확인 · 변경]으로 다시 열 수 있고, [처음부터 다시]로 새로 시작할 수 있습니다.

추정 외곽 (빨간 점멸)

ASC나 DXF에 PADS 보드 외곽선(Board Outline)이 없으면, 프로그램이 그림 선(2D Line) 조각을 이어 부품을 감싸는 외곽을 추정합니다. 이때 미리보기의 외곽선이 빨간색으로 깜빡이고 ‘추정 외곽 · PADS 보드 외곽선 없음’ 이름표가 붙으며, 보드 패널과 보드 확인 창에 안내가 나옵니다. 추정 외곽으로도 작업은 계속할 수 있지만, 모양이 실제와 다르면 높이 · 보드 밖 검사가 틀릴 수 있습니다. 설계를 고칠 수 있으면 PADS Layout에서 다음처럼 외곽을 만들어 주세요.

  1. 외곽 그림 선(DXF로 가져온 2D Line)이 있는 층을 켜고, 끊어진 곳이 없는지 확인합니다.
  2. [Drafting] 도구 모음 → [Board Outline and Cut Out]을 고르고, 그림 선을 따라 외곽을 끊김 없이 하나로 닫히게 그립니다. 모서리 곡선은 Arc로 그립니다.
  3. 기존 외곽 그림 선은 지우거나 다른 층으로 옮깁니다.
  4. [File] → [Export] → ASCII(*.asc)로 다시 내보내 프로그램에 넣습니다.

설계를 고칠 수 없으면 추정 외곽으로 진행하거나, 외형 기준을 [직접 입력]으로 바꿉니다.

2. 부품 모델 확인 · 보정

설명용 도식 · 실제 프로그램 화면이 아님

3D 자동 채우기와 자동 정렬

ASC를 열 때는 이미 받아 둔 모델만 쓰고, 부품 3D 패널의 [자동 채우기](F5)를 누르면 인터넷에서 KiCad 모델과 부품 정보를 더 찾습니다. 채우는 순서는 다음과 같습니다.

  1. KiCad 실제 모델: Footprint · PartType · BOM 품번, 품번 끝 패키지 코드(TI DBV · DBQ · PW 등), 온라인 부품 정보의 패키지 이름, 패드 배치(핀 수 · 간격 · 몸체 크기 · 노출패드)로 찾고, 패드와 실제로 맞는 모델을 고릅니다. 이름에 패키지가 없어도 찾습니다(예: LMR51606XF → SOT-23-6).
  2. 칩 부품 표준 생성: 0402~2512 칩 저항 · 커패시터 · 인덕터 등
  3. 패키지 생성: KiCad에 없으면 패키지 사전(SOIC · SOP · SSOP · QSOP · TSSOP · MSOP · SOT · SC-70 · PowerSSO · HSOP · QFN · DFN · LQFP · TQFP · SOD · SMA/SMB/SMC · PowerPAK · 전해 커패시터 · 파워 인덕터 · 수정/발진기 · 칩 어레이)에서 패드에 맞는 패키지를 골라 패드 위치에 리드를 붙여 만듭니다(예: L9733XP → PowerSSO-28).
  4. 간이 생성: 그래도 없으면 패드 모양으로 대략적인 형상을 만듭니다.

ASC 입력이면 핀 번호까지 읽어 IC 1번 핀과 다이오드 극성도 자동으로 맞춥니다. 커넥터 · 스위치처럼 패키지가 아닌 부품은 STEP을 넣어 주세요.

3D 상태로 확인하기

목록 왼쪽의 점 색이 할 일을 알려 줍니다. 목록 위 필터 칩 전체 · 없음 · 확인 · 완료로 골라 볼 수 있고, 점에 마우스를 올리면 자세한 상태가 나옵니다.

빨강없음 · 임시 박스 — 3D를 찾지 못했거나 상자로 대신 채운 부품. STEP/ZIP을 넣어 실제 3D로 바꿉니다.
주황확인 필요 · 1번핀 확인 · 극성 확인 — 패드에 자동으로 맞추지 못했거나, 모양이 대칭이라 방향을 확정하지 못한 부품. 확인/보정에서 위치 · 회전을 맞추고, 1번 패드(분홍)와 비교해 틀리면 180° 돌립니다.
파랑간이 생성 · 표준 자동생성 · 패키지 생성 — 만들어 넣은 형상. 대부분 그대로 쓰되, 간이 생성은 높이 · 모양이 중요하면 STEP으로 바꾸고 전해 커패시터는 높이를 확인합니다.
회색KiCad 3D · 사용자 3D추가 · 3D 제외 · 자유 배치 — 실제 모델이거나 사용자가 정한 부품. 할 일이 없습니다.

미리보기에서 부품을 누르면 목록에서 그 부품이 골라지고 하늘색 점선으로 깜빡이며, 상태 막대에 위치번호 · 높이 · 면이 표시됩니다.

3D가 없는 부품 채우기

  • BOM: 엑셀 · CSV(형식 자유)를 넣으면 품번으로 찾는 정확도가 올라갑니다.
  • [3D 없으면 임시 박스](기본 켜짐): 3D가 없는 부품을 옆 칸의 높이(기본 1.0mm) 상자로 채웁니다.
  • [온라인 검색]: 부품을 고르고 SnapMagic · SamacSys · Ultra Librarian · Octopart에서 STEP/ZIP을 받아 그 행에 끌어다 놓습니다.
  • [STEP/ZIP 일괄 추가]: 여러 파일을 한 번에 넣으면 파일명 · 품번으로 부품을 자동 매칭합니다.
  • [STEP/ZIP 지정]: 선택한 부품 하나에 파일을 지정합니다.
  • [간이 3D]: 패드 모양으로 간이 3D를 만듭니다.

부품 행을 오른쪽 클릭하면 확인/보정 · 온라인 검색 · STEP/ZIP 지정 · 간이 3D · 3D 몸체 색 지정 · 미리보기에서 숨기기 · 위치번호별 설정 · 등록 삭제 메뉴가 열립니다. 숨기기는 미리보기에서만 숨기고 STEP에는 그대로 들어가며, 등록 삭제는 공유 라이브러리에서도 지워집니다.

확인 · 보정 (부품 더블클릭 또는 Enter)

3D 모델을 패드(금색) · 패드 위치(하늘색 테두리) · 1번 패드(분홍) · PCB 윗면(초록선)과 비교합니다.

  • Z −90°(Q) · Z +90°(E) · 180° 1번핀 반전(R) · X축 / Y축 90° 회전
  • 좌표 입력 또는 마우스로 끌어 이동, 바닥을 PCB 면에 맞춤(F)
  • [자동 정렬 다시] · [처음 상태로] · [임시 박스로]

보정 내용과 3D 등록은 Footprint 단위로 라이브러리에 저장되어, 같은 Footprint를 쓰는 모든 부품과 다음 보드에 적용됩니다. 한 부품만 다르게 하려면 위치번호별 설정을 씁니다.

위치번호별 설정

같은 Footprint를 쓰는 부품 중 한 부품만 따로 3D를 지정 · 보정하거나 3D에서 뺄 수 있습니다. ASC를 고치지 않고 프로그램 안에서만 바뀝니다. 예를 들어 테스트 패드 Footprint가 Top(TP11)과 Bottom(TP12)의 같은 자리에 있고 여기에 SUB 보드 3D를 넣으면 SUB 보드가 위아래로 두 번 나타나는데, 이때 Bottom 쪽(TP12)만 빼면 됩니다.

  1. 목록에서 그 Footprint 행을 오른쪽 클릭합니다.
  2. [위치번호별 설정] → 위치번호(Top/Bottom 표시)를 고릅니다.
  3. 이 부품만 3D 빼기 또는 이 부품만 따로 설정을 누릅니다. 되돌릴 때는 [3D 다시 넣기] 또는 [분리 해제]를 씁니다.

3D 화면에서 부품을 누른 뒤 오른쪽 클릭해 바로 고를 수도 있습니다. 설정은 보드(ASC 파일 이름)별로 저장되어 다시 열어도 유지되며, [3D 자동 채우기]는 따로 설정한 부품을 건드리지 않습니다.

3D 자유 배치

ASC에 없는 부품(STEP · ZIP)을 보드 위 원하는 자리에 놓아 컨셉과 간섭을 확인합니다. 설계가 끝난 보드에 다른 부품을 올려 보거나, SUB 보드를 MAIN 보드에 조립해 볼 때 씁니다.

  • 놓기: 미리보기 도구 막대의 보라색 F 버튼(단축키 F)이나 부품 3D 패널의 [3D 자유 배치] → 파일 선택 → 보드 중앙에 놓입니다. 3D 화면의 빈 곳을 오른쪽 클릭해 [여기에 3D 자유 배치]를 고르면 클릭한 자리에 놓입니다(Bottom 보기에서는 Bottom 면).
  • 옮기기: 자유 배치 부품을 눌러 그대로 끌면 보라색 점선 윤곽이 따라오며 옮겨집니다. 확대 · 이동 도구가 켜져 있으면 먼저 끄세요.
  • [자유 배치 편집]: 이름(위치번호), X · Y(mm), 회전(15°씩, 직접 입력 가능), 면(Top/Bottom), 띄움 높이(스페이서 · 적층 확인용), 복제(X +5mm 옆에 하나 더) · 삭제. 세밀한 회전 · 이동은 확인/보정 창에서 합니다.

자유 배치 부품도 높이 초과 · 보드 밖 검사와 STEP 저장에 함께 들어갑니다. 보드별로 저장되어 다음에 열어도 그대로 있고, 다른 보드에는 나타나지 않습니다.

높이 확인

1단계에서 넣은 높이 제한을 넘는 부품은 빨간 테두리, 보드 밖 부품은 노란 테두리로 표시되고, 엑셀 리포트에도 정리됩니다.

3. 결과 저장 · 검토

설명용 도식 · 실제 프로그램 화면이 아님

미리보기로 확인

미리보기는 기본으로 위(Top) · 앞(Front) · 옆(Side) 보기를 함께 보여 줍니다. 범례 색은 회색 = 3D 모델, 파랑 = 생성 3D, 주황 = 임시 박스, 보라 = 자유 배치, 빨간 테두리 = 높이 초과, 노란 테두리 = 보드 밖입니다.

  • [전체 보기](Home) · [확대](+) · [축소](−) · 마우스 휠, [이동](가운데 버튼으로 끌어도 됨)
  • [영역 확대](Z): 끌어서 고른 영역을 크게 봅니다. ESC 또는 한 번 클릭하면 풀립니다.
  • [Top / Bottom](B): 위에서 본 모습과 아래에서 본 모습(좌우 반전)을 전환합니다.
  • [부품명 표시](L): 없음 · 선택 · 전체, 위치번호 또는 품번
  • [앞 · 옆 단면](V): 끄면 위 보기 하나만 크게 봅니다(기본: 켜짐).

검사 패널 (Alt+3)

배치 부품 수와 실제 3D · 생성 3D · 임시 박스 개수, 보드 외형 · 두께, 최대 높이(Top/Bottom), 높이 초과 · 보드 밖 부품을 보여 줍니다. 확인할 부품 목록을 누르면 그 부품으로 바로 갑니다. 추정 외곽이면 보드 외형 항목이 빨간 느낌표로 표시됩니다.

목적에 맞게 저장하기 (저장 패널, Alt+4)

  • [3D STEP 저장](Ctrl+E) — 핵심 결과물. 기구 설계에 활용하는 3D 모델입니다(기본 파일명 <보드>_3D.step). 보드 표면(ASC 입력 시: 없음 / 실크 / 실크 + 동박, 기본은 실크 + 동박)과 부품명 각인(없음 / 선택 / 전체, 기본은 전체)을 고릅니다. 130 × 100mm 보드를 기본값으로 저장하면 약 150MB · 40초이며, 가벼운 파일이 필요하면 표면과 각인을 ‘없음’으로 바꾸세요. 저장은 따로 진행되어 상태 막대의 초록 진행바가 올라가는 동안에도 다른 작업을 할 수 있습니다. 저장 중에 프로그램을 닫으면 저장이 취소됩니다.

부가 기능

  • PNG — 현재 미리보기 그림(<보드>_preview.png, 검토 · 공유용)
  • 엑셀 리포트 — 배치 목록, 3D 없음, 높이 초과, 보드 밖 부품(<보드>_report.xlsx)

다음에 이어서 하려면 [프로젝트 저장](Ctrl+S)으로 .p3d 파일을 남깁니다. 넣은 파일 · 보드 설정 · PCB 색상을 다시 열 수 있습니다.

보고서는 모델을 만든 뒤 확인할 항목을 모아 설계 검토를 돕는 목록이며, 3D 간섭 검사나 제조 적합성 검증을 대신하지 않습니다.

제조 전에 확인하세요

만들어진 3D 모델 · STEP · 보고서는 설계 검토를 돕는 참고 자료입니다. 부품 형상 · 방향 · 높이 · 보드 외형이 실제와 다를 수 있으니, 기구 설계 · 제작 · 양산에 쓰기 전에 원본 설계와 치수 · 방향을 직접 비교하세요.

부품 라이브러리 · KiCad 3D

한 번 채운 모델.
다음 설계에도.

  • 팀 공유 라이브러리: 등록한 3D(정렬 정보, STEP, KiCad에서 받은 모델), 위치번호별 설정, 자유 배치, 온라인 확인 결과가 라이브러리 폴더에 저장되어 다음 보드부터 자동으로 쓰입니다. 환경설정의 부품 라이브러리 폴더에서 [변경…]으로 NAS · 공유 폴더를 지정하면 팀이 함께 씁니다. 기본 위치: 문서\PCB3D_Library
  • KiCad 3D 모델: PC에 KiCad가 설치돼 있으면 설치 폴더의 모델을 씁니다. 없으면 필요한 모델만 인터넷(gitlab.com, raw.githubusercontent.com)에서 받습니다.
  • 인터넷 연결: 보드 파일과 설계 정보는 외부로 보내지 않습니다. KiCad 모델을 받을 때, [온라인 검색]으로 웹 브라우저를 열 때, 부품 정보 온라인 확인(기본 켜짐, 품번만 JLCPCB/LCSC 부품 검색으로 보냄)에 인터넷을 씁니다. 온라인 확인은 환경설정에서 끌 수 있고, 끄면 이름과 패드 배치만으로 찾습니다.
  • 도움말: 버튼에 마우스를 올리면 뜨는 ? 배지를 누르거나, F1(마우스가 올라간 버튼 설명) · Shift+F1(누르는 버튼마다 설명)을 씁니다. 처음 쓰는 분은 환경설정에서 아이콘 아래 이름 표시를 켜 두면 편합니다.

문제 해결

막히는 곳에서.
바로 다음 단계로.

설치 시 ‘Windows의 PC 보호’ 창[추가 정보] → [실행]. 코드 서명이 없는 프로그램에 뜨는 정상 경고입니다. [실행] 버튼이 없거나 회사 PC에서 막히면 설치가 막힐 때를 보세요.
보드 모양이 다르고 부품이 보드 밖에 뜸ASC에 보드 외곽선이 없는 경우입니다. 3.0은 그림 선으로 추정 외곽을 만듭니다. 추정이 틀리면 위 1. 설계 파일 입력의 PADS 수정 방법을 따르거나 외형 기준을 [직접 입력]으로 바꾸세요.
DXF를 넣었는데 외곽이 안 잡힘DXF의 원점 · 단위가 ASC와 다르면 부품을 감싸지 못해 쓰지 않습니다. 같은 설계에서 내보낸 DXF인지 확인하세요.
다음 단계로 안 넘어감보드 두께를 확인하지 않은 상태입니다. [보드 확인 · 변경]에서 두께를 확인하세요.
같은 3D가 위아래로 두 번 나옴같은 Footprint를 Top · Bottom에 쓰는 경우입니다. 위치번호별 설정으로 한쪽만 3D에서 빼세요.
KiCad 모델 · 부품 정보를 못 받음회사 방화벽에서 gitlab.com, raw.githubusercontent.com, jlcpcb.com 접속을 허용하거나 PC에 KiCad를 설치하세요.
STEP 파일이 너무 큼보드 표면을 ‘없음’ 또는 ‘실크’로, 부품명 각인을 ‘없음’으로 바꾸세요.
처음 열 때 느림계산한 형상은 %LOCALAPPDATA%\PCB3D\cache에 저장되어 같은 보드는 다음부터 빨리 열립니다.
프로젝트를 열 때 “ASC 파일을 찾을 수 없습니다”.p3d는 원본 파일 위치를 기억합니다. 파일을 원래 자리에 두거나 다시 넣으세요.
