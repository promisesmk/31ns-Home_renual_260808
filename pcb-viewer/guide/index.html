시작하기 전에

시작은 가볍게.
준비는 빠짐없이.

PCB 3D Builder는 PADS ASCII(.asc) 파일 하나로 PCB 3D STEP을 만드는 Windows 프로그램입니다. ASC가 없으면 DXF와 좌표 파일, 또는 보드 치수로도 만들 수 있습니다. 이 가이드는 v2.1 사용설명서와 프로그램 소스를 바탕으로 하며, 버튼 이름은 프로그램 표기를 그대로 [ ] 안에 적었습니다.

  • 실행 환경: Windows 10 / 11, 64비트
  • 꼭 필요한 것(하나): PADS ASCII(.asc) 파일, 또는 DXF(필요하면 좌표 파일 함께), 또는 보드 치수
  • 있으면 좋은 것(선택): BOM(부품 명세서, 엑셀 · CSV), 부품 STEP · ZIP, 데이터시트 패키지 도면 PDF
  • 파일 넣는 법: 모든 파일은 창 어디에나 끌어다 놓으면 알맞은 곳으로 들어갑니다. 엑셀 · CSV는 내용을 보고 좌표 파일인지 BOM인지 판단하고, 부품 목록의 특정 행 위에 놓으면 그 부품에 바로 들어갑니다.

1. 설계 파일 입력

설명용 도식 · 실제 프로그램 화면이 아님

처음 실행하면 작업 방식을 먼저 고릅니다. ASC와 DXF는 함께 넣어야 하는 조합이 아니라 둘 중 하나로 시작하는 입력 경로입니다(ASC로 시작할 때 보드 외형용 DXF를 더할 수는 있습니다). 고르기 전에는 다음 단계로 진행되지 않습니다.

① ASC 파일넣는 파일: ASC 1개 (+ 보드 외형용 DXF 선택)
장점: 파일 1개, STEP에 실크 · 동박 · 배선까지, 보드 두께 참고값 자동
단점: PADS 전용
② DXF (+ 좌표 파일)넣는 파일: DXF Top · Bottom(하나 이상) + 필요하면 좌표 파일
장점: 기구 외형 그대로, PADS 외 CAD도 가능, PADS DXF는 좌표 파일 없이도 가능
단점: STEP에 실크 · 동박 없음(보드 판만)
  1. 방식을 고르면 파일 넣기 창이 열립니다. 파일을 한꺼번에 끌어다 놓으면 종류를 자동으로 구분하고, 필요한 파일이 다 들어오면 [확인]이 켜집니다.
  2. ASC를 넣으면 보드 외곽 · 장착홀 · 부품 배치(Top/Bottom) · 패드 · 실크 · 배선 · 동박을 읽고 3D 자동 채우기까지 진행한 뒤 보드 확인 창을 띄웁니다.
  3. DXF를 넣으면 DXF 입력 창에서 Top · Bottom을 고르고, 다른 면 DXF와 좌표 파일을 함께 넣습니다. 프로그램이 DXF 내용을 확인해, 위치번호 · Footprint가 들어 있는 PADS DXF면 좌표 파일을 선택으로, 아니면 필수로 바꿉니다. 좌표 파일 없이 진행하면 정확하지 않을 수 있는 부분을 알려 줍니다.
  4. BOM(선택)은 이때 함께 넣거나 2단계에서 넣습니다. 넣으면 품번으로 부품 모델을 찾는 정확도가 올라갑니다.
  5. 보드 확인 창에서 외형 기준(ASC · DXF · 직접 입력)과 보드 두께를 확인합니다. 두께는 필수 확인 항목이라, 확인하기 전에는 다음 단계로 넘어가지 않습니다. ASC와 DXF가 모두 있으면 DXF가 외형 기준으로 우선합니다.
  6. 필요하면 높이 제한(케이스 내부 높이)을 넣습니다. 초과 부품은 빨간 테두리로 표시되고 보고서에도 정리됩니다.
  7. PCB 색상을 견본(그린 · 블루 · 레드 · 블랙 · 화이트 · 옐로 · 퍼플 · 매트 그린)이나 [직접…]으로 고른 뒤 [다음 단계: 부품 3D →]로 진행합니다.

[파일 다시 넣기…] · [↺ 처음부터 다시 선택]으로 언제든 다시 시작할 수 있고, [보드 확인 · 변경…]으로 두께 · 높이 제한 · 외형 기준을 다시 열 수 있습니다.

2. 부품 모델 확인 · 보정

설명용 도식 · 실제 프로그램 화면이 아님

3D 자동 채우기와 자동 정렬

[3D 자동 채우기]는 라이브러리에 이미 등록된 부품은 그대로 쓰고, 나머지는 KiCad 3D 라이브러리의 실제 모델 → 표준 형상 → 패드 기반 간이 모델 순으로 채웁니다. STEP 모델은 여러 축 방향 가운데 핀이 패드와 가장 잘 맞는 방향으로 자동 정렬되고, ASC 입력이면 핀 번호를 알 수 있어 IC 1번 핀 · 다이오드 극성까지 맞춥니다. 자동 결과가 모두 정확하지는 않으므로, 아래 순서로 확인합니다.

3D 상태로 확인하기

  • 부품 목록은 기본으로 3D 상태별로 모아서 보여 줍니다. 3D 상태 머리글을 누르면 상태별로 골라 볼 수 있고, 빨간색은 3D 없음, 주황색은 확인 필요입니다.
  • 3D 상태(프로그램 표기): 사용자 3D추가 · KiCad 3D(실제 모델), 직접 만든 3D · 표준 자동생성 · 간이 생성(치수나 패드로 만든 모델), 임시 박스(크기만 나타내는 상자), 없음, 그리고 확인이 필요한 확인 필요 · 1번핀 확인.
  • 목록에서 고른 부품은 미리보기에서 검은 점선으로 깜빡이며, Bottom 부품을 고르면 Bottom 보기로 바뀝니다. 검색칸으로 Footprint · 위치번호 · 품번을 찾을 수 있습니다.

3D가 없는 부품 채우기

  • [온라인 검색] → 끌어다 놓기: 3D가 없는 부품을 고르고 [온라인 검색]으로 받은 STEP · ZIP을 그 행에 끌어다 놓습니다.
  • [STEP/ZIP 일괄추가]: 여러 파일을 한 번에 넣으면 파일명 · 품번으로 부품을 자동 매칭합니다. 일괄 매칭을 위해 Footprint 명칭과 각 STEP 파일명을 일치시켜 주세요. ZIP을 넣을 때는 ZIP 파일 이름이 아니라 압축 안에 들어 있는 각 STEP 파일의 이름이 기준입니다. 파일명은 확장자(.step · .stp)를 뺀 이름으로 비교하며, 대소문자와 기호(- _ 공백 등)는 구분하지 않습니다. 예: Footprint가 SOT-23이면 SOT-23.step 또는 sot23.stp. 매칭되지 않은 파일은 등록 결과 창에 표시되니 [STEP/ZIP 개별지정]이나 해당 행에 끌어다 놓기로 지정합니다.
  • [STEP/ZIP 개별지정]: 선택한 부품 하나에 파일을 지정합니다.
  • [등록 삭제]: 잘못 연결된 모델을 지웁니다. 지우면 다음 자동 채우기 때 다시 찾습니다.
  • 색상: 목록 맨 왼쪽 칸을 클릭해 그 Footprint의 3D 몸체 색을 정합니다(우클릭 → 해제). 라이브러리에 저장됩니다.

데이터시트 PDF로 3D 만들기 ([PDF로 3D 만들기])

  1. 패키지 형태를 7가지 중에서 고릅니다: 양쪽 리드형, 4면 리드형, 리드 없는형, 칩형 2단자, 몰드 다이오드형, 원통형, 박스형.
  2. [PDF 열기…]를 누르거나 창에 PDF를 끌어다 놓고 [PDF 치수 읽기]로 치수표를 읽습니다. PDF가 없으면 [패드에서 추정]을 쓰거나 치수를 직접 입력합니다.
  3. 치수 칸에 들어온 값을 도면과 비교해 확인 · 수정하고 [미리보기]로 모양을 봅니다.
  4. [3D 등록]을 누르면 패드에 자동으로 맞춰 등록됩니다.

치수표를 글자로 읽기 때문에 그림으로만 된 도면은 자동 인식되지 않을 수 있고, 7가지 밖의 형상은 만들 수 없습니다. 그런 부품은 STEP · ZIP으로 등록합니다.

확인 · 보정 ([확인 / 보정] 또는 부품 더블클릭)

선택한 부품 하나를 STEP 실제 색으로 음영 처리한 위(Top) · 고정 각도 3D · 앞(Front) 보기로 열어, 패드(금색, 하늘색 테두리) · 1번 패드(분홍) · 실크(흰색)와 비교합니다. 보드 전체가 아닌 부품 하나를 보는 화면입니다.

  • Z ±90° / 180°, X / Y 90° 회전
  • 좌표 입력(0.05 ~ 1mm 단위), 마우스로 끌어 이동
  • [⇊ 바닥을 PCB면(Z=0)에 맞춤]: 부품 바닥을 보드 면에 맞춥니다.
  • [자동 정렬 다시] · [임시 박스로] · [↺ 처음 상태로]로 다시 맞추고, [저장 및 완료]로 저장합니다.

높이 확인

1단계에서 넣은 높이 제한을 넘는 부품은 빨간 테두리로 표시되고, 엑셀 보고서의 높이초과 시트에도 정리됩니다.

3. 결과 저장 · 검토

설명용 도식 · 실제 프로그램 화면이 아님

미리보기로 확인

보드 전체는 위에서 본 모습(Top)과 아래에서 본 모습(Bottom, 좌우 반전)을 전환하고, 앞(Front) · 옆(Side)에서 본 모습을 함께 봅니다. 영역을 끌어 확대하고, 끌지 않고 클릭하거나 Esc를 누르면 확대가 풀립니다. 부품명 표시(없음 · 선택 · 전체, 위치번호 또는 품번)를 고를 수 있고, 부품을 클릭하면 정보가 표시됩니다.

목적에 맞게 저장하기

  • [3D STEP 저장] — 핵심 결과물. 기구 설계에 활용하는 3D 모델입니다. 보드 표면 표현(ASC 입력 시: 없음 / 실크 / 실크 + 동박)과 부품명 각인(없음 / 선택 / 전체)을 고릅니다. 기본값은 모든 옵션이며, 사용설명서의 예로 130 × 100mm 보드는 약 150MB · 40초입니다. 저장은 별도로 진행되어 그동안 다른 작업을 계속할 수 있습니다.

부가 기능

  • [미리보기 이미지 (PNG)] — 이미지 저장(검토 · 공유용)
  • [배치 리포트 (엑셀)] — 배치 · 검토 항목 보고서

보고서는 모델을 만든 뒤 확인할 항목을 모아 설계 검토를 돕는 목록이며, 3D 간섭 검사나 제조 적합성 검증을 대신하지 않습니다.

제조 전에 확인하세요

만들어진 3D 모델 · STEP · 보고서는 설계 검토를 돕는 참고 자료입니다. 부품 형상 · 방향 · 높이 · 보드 외형이 실제와 다를 수 있으니, 기구 설계 · 제작 · 양산에 쓰기 전에 원본 설계와 치수 · 방향을 직접 비교하세요.

부품 라이브러리 · KiCad 3D

한 번 채운 모델.
다음 설계에도.

  • 팀 공유 라이브러리: 등록한 부품(정렬 정보, STEP, KiCad에서 받은 모델)은 라이브러리 폴더에 저장되어 다음 보드부터 자동으로 쓰입니다. 왼쪽 아래에 표시된 라이브러리 폴더 경로를 눌러 NAS · 공유 폴더로 바꾸면 팀이 함께 씁니다. 기본 위치: 문서\PCB3D_Library
  • KiCad 3D 모델: PC에 KiCad가 설치돼 있으면 설치 폴더의 모델을 씁니다. 없으면 필요한 모델만 인터넷(gitlab.com, raw.githubusercontent.com)에서 받아 라이브러리 폴더에 저장합니다.
  • 인터넷 연결: 보드 파일은 내 PC에서 처리합니다. 공개 KiCad 모델의 목록 · 파일을 받을 때와 [온라인 검색]으로 웹 브라우저를 열 때 인터넷을 사용합니다.
