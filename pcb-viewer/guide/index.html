시작하기 전에

시작은 가볍게.
준비는 빠짐없이.

PCB 3D Builder는 PCB 설계 파일로 부품까지 붙은 PCB 3D STEP을 만드는 Windows 프로그램입니다. PADS ASCII(.asc) 하나로 만들 수 있고, ASC가 없으면 거버 + 좌표 파일, 또는 DXF + 좌표 파일, 또는 보드 치수로도 만들 수 있습니다. 이 가이드는 4.0 사용설명서를 바탕으로 하며, 버튼 이름은 프로그램 표기를 그대로 [ ] 안에 적었습니다.

  • 실행 환경: Windows 10 / 11, 64비트
  • 꼭 필요한 것(하나): PADS ASCII(.asc) 파일, 또는 거버 + 좌표 파일, 또는 DXF(필요하면 좌표 파일 함께), 또는 보드 치수
  • 있으면 좋은 것(선택): BOM(부품 명세서, 엑셀 · CSV), 부품 STEP · ZIP
  • 파일 넣는 법: 모든 파일은 창 어디에나 끌어다 놓으면 알맞은 곳으로 들어갑니다. 파일 여러 개 · 폴더 · ZIP 모두 되며, 외주처에서 받은 납품 폴더를 통째로 넣어도 그 안의 거버 · 좌표 파일 · BOM을 찾아 씁니다.
.asc보드 입력(가장 정확)
거버 폴더 · ZIP · 거버 파일들보드 입력(좌표 파일과 함께). 확장자가 아니라 내용으로 거버 · 드릴을 알아봅니다(.pho · .gbr · .art · .gtl · .drl 등).
.dxf보드 외형(파일 이름에 BOT이 있으면 Bottom)
엑셀 · CSV · TXT좌표 파일인지 BOM인지 내용으로 판단
.step · .stp · .zip부품 3D 등록(보드를 연 뒤). 부품 목록의 특정 행 위에 놓으면 그 부품에 바로 들어갑니다. 3D 모델이 없는 ZIP은 등록하지 않고 알려 줍니다.

4.0에서 달라진 점: 거버 + 좌표 파일로 보드 만들기, 거버 그대로의 보드 표면(동박 · 노출 패드 · 실크), 파일을 끌어다 놓는 시작 화면, 남은 시간을 보여 주는 진행 카드, 3D가 없는 부품 지우기, 높이 제한 기본 20mm, 보드를 열 때마다 보드 확인 창, 큰 보드에서 빨라진 미리보기 · STEP 저장. 2.x · 3.0 위에 그대로 설치하면 부품 라이브러리 · 설정 · 프로젝트 파일은 유지됩니다.

1. 설계 파일 입력

설명용 도식 · 실제 프로그램 화면이 아님

처음 화면 가운데 카드에 보드 파일을 끌어다 놓거나 [파일 선택]을 누릅니다. 넣은 파일로 작업 방식을 자동으로 고릅니다(ASC → 거버 → DXF 순서).

① ASC 파일넣는 파일: ASC 1개 (+ 보드 외형용 DXF 선택)
장점: 파일 1개 · 핀 번호까지 정확 · 보드 두께 참고값 자동
단점: PADS 전용
② 거버 + 좌표 파일넣는 파일: 거버 폴더(ZIP) + 좌표 파일 (+ BOM · DXF 선택)
장점: 모든 CAD · PCB 발주와 SMT 때 누구나 받는 파일 · 외곽 · 장착홀 · 동박이 거버 그대로
단점: 핀 번호가 없어 1번핀 · 극성은 실크로 추정
③ DXF (+ 좌표 파일)넣는 파일: DXF Top · Bottom(하나 이상) + 좌표 파일(필요할 때)
장점: 기구 외형 그대로 · PADS DXF는 좌표 파일 없이도 됨
단점: STEP에 실크 · 동박 없음(보드 판만)

ASC 파일

보드 외곽 · 장착홀 · 부품 배치(Top/Bottom) · 패드 · 실크 · 배선 · 동박을 읽고 3D 자동 채우기까지 진행합니다. PADS PowerPCB V4 등 옛 버전부터 최신 버전까지 읽습니다(좌표 단위 BASIC · MILS · METRIC · INCHES).

거버 + 좌표 파일 (ASC가 없을 때)

  • 거버 폴더(또는 ZIP)와 좌표 파일을 함께 끌어다 놓으면 바로 열립니다. 거버만 넣으면 좌표 파일을 넣는 창이 뜹니다.
  • 거버에서 보드 외곽 · 드릴(장착홀) · 패드 · 동박 · 실크를, 좌표 파일에서 위치번호 · 회전 · Top/Bottom · Footprint · 값을 읽습니다. 외곽 레이어가 따로 없는 거버(PADS 등)는 도면 레이어의 선에서 보드 외곽을 찾습니다.
  • CAD마다 좌표 파일 형식이 달라도 됩니다. 좌표 원점 · Y축 방향 · 단위(mm/mil) · Bottom 회전 규칙은 거버 패드 위치에 맞춰 자동으로 정합니다.
  • 부품마다 거버 패드를 모아 Footprint 패드 배치를 만들고, 그것으로 3D를 찾고 맞춥니다. 좌표 파일에 핀 수(Pins) 열이 있으면 더 정확하고, 패드 묶음이 애매한 Footprint는 보드 패널에 ‘거버 패드 묶음 확인 필요’로 표시됩니다.
  • 보드 표면은 거버 그림 그대로입니다. 노출 패드는 동박 중 솔더마스크가 열린 곳, 실크는 마스크가 열린 곳을 뺀 모양입니다.
  • 거버에는 핀 번호가 없어 IC 1번핀 · 다이오드 극성은 실크 표시로 추정합니다. 정하지 못한 부품은 ‘1번핀 확인’으로 표시되니 확인 · 보정 창에서 확인하세요.

DXF (+ 좌표 파일)

DXF를 넣으면 DXF 입력 창에서 Top · Bottom을 고르고, 다른 면 DXF와 좌표 파일(권장)을 함께 넣습니다. 위치번호 · Footprint가 들어 있는 PADS DXF면 좌표 파일이 선택, 아니면 필수입니다. 한 면만 넣으면 그 면만 PCB 3D가 생성될 수 있다고 알려 줍니다.

보드 확인

  • 보드를 열면 어떤 방식이든 보드 확인 창(외형 기준 + 두께 + 높이 제한)이 한 번 뜹니다. [보드 확인 · 변경…]으로 언제든 다시 엽니다.
  • 보드 두께는 필수 확인 항목입니다. ASC 도면 문구(1.6T, 1.0T/2Layer 등)에서 참고값을 넣어 두지만, 확인하기 전에는 다음 단계로 넘어가지 않습니다.
  • 높이 제한(케이스 내부 높이): 넘는 부품은 빨간 테두리로 표시됩니다. 기본값은 Top · Bottom 20mm이고, 0을 넣으면 검사하지 않습니다.
  • 보드 외형 기준: ASC / 거버 / DXF / 직접 입력. 자동이면 DXF → 거버 → ASC 순서로 쓰고, [직접 입력]은 가로 · 세로 · 모서리 · 장착홀을 입력합니다.
  • PCB 색상: 견본(그린 · 블루 · 레드 · 블랙 · 화이트 · 옐로 · 퍼플 · 매트 그린) 또는 [직접…]. 미리보기와 STEP에 모두 적용되며 프로젝트 파일에 저장됩니다.

추정 외곽 (빨간 점멸)

보드 외곽선(Board Outline) 항목이 없어 그림 선을 이어 외곽을 추정했으면, 미리보기의 외곽이 빨간색으로 깜빡이고 보드 확인 창 · 보드 패널에 “추정 외곽”과 PADS 수정 방법이 표시됩니다. PADS Layout에서 [Drafting] → [Board Outline and Cut Out]으로 외곽을 끊김 없이 닫히게 그린 뒤 다시 내보내면 정확한 외곽이 됩니다. 설계를 고칠 수 없으면 추정 외곽으로 진행하거나 외형 기준을 [직접 입력]으로 바꿉니다.

진행 카드

보드를 불러오거나 3D를 만드는 동안 화면 가운데 진행 카드에 지금 하는 일, 진행 막대, 지난 시간, 남은 시간(예상)이 나옵니다. 남은 시간은 같은 파일을 지난번 연 시간(처음이면 파일 크기)으로 예상하며 쓸수록 정확해지고, 예상을 넘기면 “예상보다 오래 걸리고 있습니다”로 알려 줍니다.

2. 부품 모델 확인 · 보정

설명용 도식 · 실제 프로그램 화면이 아님

3D 상태로 확인하기

  • BOM(선택): 넣으면 품번으로 찾기 정확도가 올라갑니다. 형식은 자유입니다(열 자동 인식).
  • 부품 목록은 기본으로 3D 상태별로 모아서 정렬됩니다. 3D 상태 머리글을 누르면 상태별로 골라 볼 수 있고, 다른 머리글을 누르면 그 기준으로 정렬합니다.
  • 3D 상태: 사용자 3D추가(직접 넣은 STEP) · KiCad 3D · 패키지 생성 · 표준 자동생성 · 간이 생성 · 임시 박스 · 없음 · 확인 필요
  • 상태줄 오른쪽 3D 있음 %는 전체 부품 중 3D가 들어간 부품의 비율입니다(작업 진행률이 아님).
  • 목록에서 고른 부품은 미리보기에서 검은 점선으로 깜빡이며, Bottom 부품을 고르면 Bottom 보기로 자동 전환됩니다. 검색칸으로 Footprint · 위치번호 · 품번을 찾고, 위치번호는 대표 위치 + “외 n”으로 표시됩니다.

3D 자동 채우기

KiCad 3D 라이브러리에서 실제 모델을 찾아 패드에 맞춥니다. ASC 입력이면 핀 번호가 정확해 IC 1번핀 · 다이오드 극성까지 자동으로 맞춰집니다.

  1. KiCad 실제 모델: Footprint · PartType · BOM 품번, 품번 끝 패키지 코드(TI DBV · DBQ · PW 등), 온라인 부품 정보(품번으로 JLCPCB/LCSC 검색해 패키지 이름 · 몸체 크기 확인), 패드 배치(핀 수 · 간격 · 몸체 크기 · 노출 패드)로 찾습니다. 이름에 패키지가 없어도(예: LMR51606XF → SOT-23-6) 찾을 수 있고, 최종 선택은 패드와 실제로 맞는지로 정합니다.
  2. 패키지 생성: KiCad에 없으면 패키지 사전(SOIC · SOP · SSOP · QSOP · TSSOP · MSOP · SOT · SC-70 · PowerSSO · HSOP · QFN · DFN · LQFP · TQFP · SOD · SMA · SMB · SMC · PowerPAK · 전해캡 · 파워 인덕터 · 수정/발진기 · 칩 어레이 등)에서 패드에 맞는 패키지를 골라 만듭니다(예: L9733XP → PowerSSO-28, 220uF 전해캡 → 12.5 × 10mm).
  3. 그래도 없으면 칩 부품 표준 형상 → 패드 기반 간이 3D 순서로 채웁니다. 커넥터 · 스위치처럼 패키지가 아닌 부품은 STEP을 넣어 주세요.

온라인 확인은 [환경설정]에서 끌 수 있습니다. 품번만 보내며, 결과는 라이브러리 폴더에 저장되어 같은 품번은 다시 묻지 않습니다. 이미 찾아본 부품은 다시 찾지 않습니다(등록을 삭제하면 다시 찾습니다).

3D 넣기 · 고치기

  • 3D가 없는 부품(빨간 점): 선택 → [온라인 검색] → 받은 STEP/ZIP을 그 행에 끌어다 놓기
  • [STEP/ZIP 일괄추가]: 여러 파일을 한 번에 넣으면 파일 이름 · 품번으로 부품을 자동 매칭합니다. 결과 창에 등록한 3D, STEP이 없는 ZIP, 어느 부품인지 찾지 못한 파일을 나눠 알려 줍니다.
  • [STEP/ZIP 개별지정]: 선택한 부품 하나에 STEP/ZIP 파일을 지정합니다.
  • 색상(목록 맨 왼쪽 칸): 그 Footprint의 3D 몸체 색을 정합니다(오른쪽 클릭 → 색 지정 해제). 라이브러리에 저장됩니다.
  • 확인 / 보정(더블클릭): STEP 실제 색으로 음영 처리한 Top · 3D · Front 보기에서 패드(금색) · 1번 패드(분홍) · 실크(흰색)와 비교합니다. Z ±90° / 180°, X / Y 90° 회전, 좌표 입력(0.05 ~ 1mm 단위), 마우스로 끌어 이동, 바닥을 PCB면에 자동 맞춤.
  • 등록 삭제(Delete): 3D 등록을 지웁니다(공유 라이브러리에서도 지워짐).

3D가 없는 부품 지우기

3D 등록이 없는 부품을 고르고 [등록 삭제]를 누르면, 경고 후 이 보드의 부품 목록 · 미리보기 · STEP에서 빠집니다. 3D 라이브러리와 다른 보드에는 영향이 없고, 지운 상태는 보드별로 저장되며 보드 패널의 [지운 부품 되살리기]로 되돌립니다.

위치번호별 설정

3D는 Footprint 단위로 등록되므로 같은 Footprint를 쓰는 부품은 모두 같은 3D가 붙습니다. 한 부품만 다르게 하려면 3D 화면에서 그 부품을 누르거나 오른쪽 클릭 → [위치번호별 설정]에서 위치번호를 고른 뒤 선택합니다.

  • 이 부품만 따로 설정: 목록에 Footprint · 위치번호 행이 따로 생기고, 그 행의 STEP 지정 · 확인/보정 · 색 지정은 그 부품에만 적용됩니다.
  • 이 부품만 3D 빼기: 미리보기와 STEP 저장에서 그 부품의 3D만 빠집니다.
  • 따로 설정한 행에서 [분리 해제]를 누르면 다시 원래 Footprint 설정을 따릅니다. 설정은 보드별로 라이브러리에 저장됩니다.

3D 자유 배치

미리보기 도구 막대의 보라색 F 버튼(단축키 F) 또는 3D 화면 빈 곳 오른쪽 클릭 → [여기에 3D 자유 배치]로, 설계에 없는 부품(STEP · ZIP)을 보드 위 원하는 자리에 놓아 컨셉 · 간섭을 확인합니다.

  • 목록과 미리보기에 보라색으로 표시되고, 3D 화면에서 눌러 끌면 옮겨집니다. Bottom 보기에서 놓으면 Bottom 면에 놓입니다.
  • 오른쪽 클릭 → [자유 배치 편집]: 이름 · X · Y · 회전 · 면 · 띄움 높이, [보드 중앙으로], [복제], [삭제]
  • 높이 초과 · 보드 밖 검사와 STEP 저장에 함께 들어가며, 보드별로 저장됩니다.

높이 확인

1단계의 높이 제한(기본 20mm)을 넘는 부품은 빨간 테두리로 표시되고, 엑셀 리포트에도 정리됩니다.

3. 결과 저장 · 검토

설명용 도식 · 실제 프로그램 화면이 아님

미리보기로 확인

위(Top) · 앞(Front) · 옆(Side) 단면을 함께 보여 줍니다. [앞 · 옆 단면] 버튼(V)으로 위 보기만 크게 볼 수 있고, Top / Bottom 전환, 부품명 표시(없음 / 선택 / 전체, 위치번호 또는 품번)를 고릅니다. 부품을 클릭하면 정보가 나옵니다.

목적에 맞게 저장하기

  • [3D STEP 저장] — 핵심 결과물. 기구 설계에 활용하는 3D 모델입니다. 보드 표면(ASC · 거버 입력 시: 없음 / 실크 / 실크 + 동박)과 STEP에 부품명 각인(없음 / 선택 / 전체)을 고릅니다. 기본값은 모든 옵션(실크 + 동박, 각인 전체)이며, 130 × 100mm 보드는 약 120 ~ 180MB · 40초 ~ 2분입니다. 표면을 넣을수록 STEP이 커집니다. 저장은 별도로 진행되어 그동안 다른 작업을 계속할 수 있고, 3D 화면 오른쪽 위 STEP 저장 중 카드와 상태줄 진행바에 진행 · 남은 시간이 나옵니다.

부가 기능

  • 미리보기 PNG — 검토 · 공유용 이미지
  • 배치 리포트(엑셀) — 배치 목록, 3D 없음, 높이 초과, 보드 밖 부품

보고서는 모델을 만든 뒤 확인할 항목을 모아 설계 검토를 돕는 목록이며, 3D 간섭 검사나 제조 적합성 검증을 대신하지 않습니다.

제조 전에 확인하세요

만들어진 3D 모델 · STEP · 보고서는 설계 검토를 돕는 참고 자료입니다. 부품 형상 · 방향 · 높이 · 보드 외형이 실제와 다를 수 있으니, 기구 설계 · 제작 · 양산에 쓰기 전에 원본 설계와 치수 · 방향을 직접 비교하세요.

부품 라이브러리 · KiCad 3D

한 번 채운 모델.
다음 설계에도.

  • 팀 공유 라이브러리: 등록한 부품(정렬 정보, STEP, KiCad에서 받은 모델)은 라이브러리 폴더에 저장되어 다음 보드부터 자동으로 쓰입니다. 왼쪽 아래 폴더 변경 (팀 공유)에서 NAS · 공유 폴더를 지정하면 팀이 함께 씁니다. 기본: 문서\PCB3D_Library
  • KiCad 3D 모델: PC에 KiCad가 설치돼 있으면 설치 폴더의 모델을 씁니다(인터넷 불필요). 없으면 필요한 모델만 인터넷(gitlab.com, raw.githubusercontent.com)에서 받아 라이브러리 폴더에 저장합니다.
  • 인터넷 연결: 보드 데이터는 외부로 보내지 않습니다. 온라인 부품 정보 확인을 켜 두면 품번만 JLCPCB 부품 검색으로 보냅니다.
  • 속도: 처음 불러올 때 계산한 3D 형상 · 보드 표면은 %LOCALAPPDATA%\PCB3D\cache에 저장되어, 같은 보드는 다음부터 빨리 열립니다.

문제 해결

막히는 곳에서.
바로 다음 단계로.

설치 시 ‘Windows의 PC 보호’ 창[추가 정보] → [실행]. 코드 서명이 없는 프로그램에 뜨는 정상 경고입니다. [실행] 버튼이 없거나 회사 PC에서 막히면 설치가 막힐 때를 보세요.
보드 모양이 다르고 부품이 보드 밖에 뜸ASC에 보드 외곽선이 없는 경우입니다. 그림 선으로 추정 외곽을 만듭니다. 추정이 틀리면 위 1. 설계 파일 입력의 PADS 수정 방법을 따르거나 외형 기준을 [직접 입력]으로 바꾸세요.
거버로 연 보드의 1번핀 · 극성이 틀림거버에는 핀 번호가 없어 실크로 추정합니다. ‘1번핀 확인’ 부품을 확인 · 보정 창에서 1번 패드(분홍)와 비교해 돌려 주세요. 가능하면 ASC를 쓰면 정확합니다.
거버 패드 묶음 확인 필요좌표 파일에 핀 수(Pins) 열이 있으면 더 정확해집니다. 표시된 Footprint는 3D를 확인 · 보정에서 확인하세요.
다음 단계로 안 넘어감보드 두께를 확인하지 않은 상태입니다. [보드 확인 · 변경…]에서 두께를 확인하세요.
같은 3D가 위아래로 두 번 나옴같은 Footprint를 Top · Bottom에 쓰는 경우입니다. 위치번호별 설정으로 한쪽만 3D에서 빼세요.
KiCad 모델 · 부품 정보를 못 받음회사 방화벽에서 gitlab.com, raw.githubusercontent.com, jlcpcb.com 접속을 허용하거나 PC에 KiCad를 설치하세요.
STEP 파일이 너무 큼보드 표면을 ‘없음’ 또는 ‘실크’로, 부품명 각인을 ‘없음’으로 바꾸세요.
처음 열 때 느림계산한 형상은 캐시에 저장되어 같은 보드는 다음부터 빨리 열립니다. 진행 카드의 남은 시간도 쓸수록 정확해집니다.
