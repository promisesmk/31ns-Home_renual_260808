01 / 왜 필요한가 · Why

차원을 더하고.
수고를 덜고.

PCB 설계 자료는 있는데 부품이 배치된 3D 모델이 없다면, 기구 설계와 협업하기 위해 별도 모델링을 맡기거나 직접 추가 작업을 해야 할 수 있습니다.

  • 3D 모델이 없을 때

    설계 자료만으로는 기구 설계와 주고받을 3D 모델이 없어, 별도 모델링을 의뢰하거나 추가 작업이 필요할 수 있습니다.

  • 부품마다 찾고 맞추는 수고

    부품별 3D 모델을 찾아 하나씩 배치하고 방향을 맞추는 일에는 시간과 수고가 듭니다.

  • 설계 자료에서 STEP까지

    PCB 3D Builder는 설계 자료와 부품 라이브러리로 모델을 구성하고, 확인 · 보정을 거쳐 STEP으로 전달하도록 돕습니다. 별도 모델링에 드는 시간과 비용 부담을 줄이는 데 도움이 됩니다.

만든 모델은 설계 검토를 돕는 참고 자료이므로, 기구 설계와 최종 검토는 여전히 필요합니다.

02 / 한눈에 보기 · Overview

평면에서 입체로.
다음 STEP으로.

보드 파일을 넣고, 부품 3D를 채워 확인 · 보정한 뒤, 결과를 저장하는 흐름입니다.

  1. INPUT

    보드 입력

    PADS ASCII(.asc) 또는 DXF(+ 필요하면 좌표 파일) 중 하나로 시작 · BOM은 선택

    보드 외형 기준과 두께를 확인합니다.

  2. PARTS · CHECK

    부품 확인 · 보정

    등록 모델 · KiCad 모델 · 표준 형상 · 간이 모델 · STEP · ZIP · 데이터시트 PDF

    선택한 부품의 위치 · 방향을 패드에 맞추고, 높이 제한 초과를 표시합니다.

  3. OUTPUT

    결과 저장

    STEP — 기구 설계에 활용하는 3D 모델

    부가 기능PNG: 이미지 저장 · Excel: 배치 · 검토 항목 보고서

위 3단계 그림은 흐름을 설명하는 도식이며 실제 프로그램 화면이 아닙니다.

03 / 주요 기능 · Features

모델은 채우고.
손은 덜 가도록.

  • Model Matching

    부품 모델 매칭 · 자동 정렬

    라이브러리에 등록된 부품은 그대로 쓰고, 없으면 KiCad 실제 모델 → 표준 형상 → 패드 기반 간이 모델 순으로 채웁니다. STEP 모델은 패드와 가장 잘 맞는 방향으로 자동 정렬되고, ASC 입력이면 IC 1번 핀 · 다이오드 극성도 맞춥니다. 자동 결과는 확인 · 보정의 출발점입니다.

  • From Datasheet

    데이터시트 PDF로 부품 3D 만들기

    패키지 도면 PDF의 치수표를 읽어 7가지 형상 템플릿 중 하나로 만듭니다. 읽어 온 치수는 확인 · 수정하고 미리보기로 본 뒤 등록하며, PDF가 없으면 패드에서 추정하거나 직접 입력할 수 있습니다.

  • Check & Adjust

    부품 확인 · 보정

    선택한 부품 하나를 위(Top) · 고정 각도 3D · 앞(Front) 보기로 패드 · 1번 패드 · 실크와 비교하고, 90° · 180° 회전, 좌표 입력, 마우스로 끌어 이동해 맞춥니다. 자동 정렬을 다시 하거나 임시 박스로 바꿀 수도 있습니다.

  • Board Preview

    보드 미리보기

    보드 전체는 위에서 본 모습과 아래에서 본 모습(좌우 반전)을 전환하고, 앞 · 옆에서 본 모습을 함께 봅니다. 원하는 영역을 확대하고 클릭이나 Esc로 되돌릴 수 있습니다.

  • STEP Options

    보드 표면 · 색상 · 각인

    ASC 입력이면 STEP에 실크 · 동박 · 배선까지 넣을 수 있고, PCB 색상과 부품명 각인(없음 · 선택 · 전체)을 고릅니다.

  • Height & Report

    높이 확인 · 검토 보고서

    케이스 내부 높이를 넣으면 초과 부품을 빨간 테두리로 표시합니다. 엑셀 보고서는 배치 목록 · 3D 없음(임시 박스 포함) · 높이 초과 · 외곽 이탈을 나눠 담아, 모델을 만든 뒤 확인할 항목을 모아 줍니다.

07 / 자주 묻는 질문 · FAQ

시작 전 물음표.
여기서 하나씩.

01어떤 설계 파일을 준비해야 하나요?＋

PADS ASCII(.asc) 파일 하나를 권장합니다. ASC가 없으면 DXF(Top · Bottom)와, 필요하면 좌표 파일(엑셀 · CSV)을 씁니다. BOM과 부품 STEP · ZIP, 데이터시트 PDF는 있으면 도움이 되는 선택 자료입니다.

02DXF만 있어도 사용할 수 있나요?＋

위치번호 · Footprint 같은 부품 정보가 들어 있는 PADS DXF라면 DXF만으로 진행할 수 있습니다. 그 밖의 DXF는 좌표 파일을 함께 넣어야 부품이 배치됩니다. DXF 방식의 STEP에는 실크 · 동박 없이 보드 판만 들어갑니다.

03BOM은 필수인가요?＋

아니요, 선택입니다. 넣으면 품번으로 부품 모델 후보를 찾는 정확도가 올라갑니다.

04모든 부품이 자동으로 정확하게 만들어지나요?＋

아니요. 3D 자동 채우기는 KiCad 실제 모델 → 표준 형상 → 패드 기반 간이 모델 순으로 채우고 패드에 맞춰 정렬하지만, 간이 모델 · 임시 박스로 남거나 ‘확인 필요’로 표시되는 부품이 있을 수 있습니다. 부품 목록의 3D 상태와 확인 · 보정 화면에서 확인하고, 필요하면 STEP을 등록하거나 직접 맞추세요.

05데이터시트 PDF는 어떤 조건에서 사용할 수 있나요?＋

패키지 도면의 치수표를 글자로 읽을 수 있고, 부품이 7가지 지원 형상(양쪽 리드형, 4면 리드형, 리드 없는형, 칩형, 다이오드형, 원통형, 박스형) 중 하나일 때 쓸 수 있습니다. 읽어 온 치수는 확인 · 수정하고 미리보기로 본 뒤 등록합니다. 그 밖의 부품은 STEP · ZIP으로 등록하세요.

06결과물을 어떤 형식으로 저장할 수 있나요?＋

3D STEP(기구 설계 협업용 모델), 미리보기 PNG(검토 · 공유용 이미지), 배치 리포트 엑셀(배치 목록과 3D 없음 · 높이 초과 · 외곽 이탈 항목)입니다. 결과물은 설계 검토용 참고 자료이므로 제조 전에 원본 설계와 직접 비교해 확인하세요.

07인터넷 없이 사용할 수 있나요?＋

보드 파일 처리는 내 PC에서 이뤄집니다. KiCad가 설치돼 있거나 라이브러리에 이미 저장된 모델만 쓰는 작업은 인터넷이 필요 없다고 사용설명서에 안내되어 있습니다. 공개 KiCad 모델을 새로 받거나 [온라인 검색]을 쓸 때는 인터넷에 연결됩니다.

08회사에서도 무료로 사용할 수 있나요?＋

네. 사용권 계약에 따라 개인 · 업무(상업) 목적 모두 무상으로 사용할 수 있습니다. 판매하거나 수정해 배포할 수는 없고, 원본 설치 파일 그대로 무상으로만 전달할 수 있습니다. 프로그램은 ‘있는 그대로’ 제공됩니다.

09다운로드하려면 어떻게 해야 하나요?＋

회원가입(최초 1회 이메일 인증) 후 로그인하고 회사명과 담당자명을 등록하면 받을 수 있습니다. 다운로드를 요청하면 보안을 위해 자동으로 로그아웃되며, 다시 받으려면 다시 로그인해야 합니다.

10설치할 때 ‘Windows의 PC 보호’ 경고가 떠요.＋

설치 파일에 코드 서명이 없으면 이 경고가 나타날 수 있습니다. [추가 정보] → [실행]을 누르면 설치가 진행됩니다.
